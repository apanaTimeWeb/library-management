# Manager Module Forbidden Boundaries

1. **NO FINANCE MUTATION**: Managers can view certain financial data but cannot mutate core financial records (refunds, deep billing). That is restricted to Superadmin/Admin.
2. **NO MULTI-BRANCH ACCESS**: Like Admins, Managers are restricted to a single branch.
3. **NO SYSTEM CONFIG**: Managers cannot change system-wide settings, themes, or global configurations.
