# Superadmin System Tenants Module

This module manages the tenants (businesses/organizations) in the Superadmin domain.

It strictly adheres to the Enterprise-grade micro-modularized architecture.

**Endpoints:**
- `GET /api/superadmin/system/tenants`: Get all tenants
- `GET /api/superadmin/system/tenants/:id`: Get a specific tenant
- `POST /api/superadmin/system/tenants`: Create a new tenant
- `PATCH /api/superadmin/system/tenants/:id`: Update a tenant
- `DELETE /api/superadmin/system/tenants/:id`: Soft delete a tenant
